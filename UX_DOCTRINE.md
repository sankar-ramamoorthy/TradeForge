# TradeForge — UX Doctrine

## Purpose

Defines how the system should feel cognitively to use.

TradeForge is NOT a dashboard.

It is a **decision environment for structured thinking under uncertainty**.

---

# 1. Core UX Principle

UX is not navigation.

UX is:

> cognitive flow management

The system should reduce mental fragmentation.

---

# 2. Workspace First Design

Users do NOT interact with “screens”.

They operate inside:

- Persona Workspaces

Each workspace represents:
- a cognitive environment
- a decision context
- a live reasoning space

---

# 3. Cognitive Surfaces (not UI pages)

Each workspace contains surfaces:

## 3.1 Briefing Surface
- what matters right now
- regime context
- key shifts

## 3.2 Exposure Surface
- active positions
- risk distribution
- commitments

## 3.3 Opportunity Surface
- ranked scenarios
- watchlist items
- emerging setups

## 3.4 Decision Queue
- decisions requiring action
- lifecycle state tracking

## 3.5 Review Surface
- past decisions
- outcomes vs intent
- learning feedback

---

# 4. UX Flow Principle

UX should follow:

> context → interpretation → decision → reflection

NOT:
> navigation → selection → execution → exit

---

# 5. Cognitive Continuity Rule

The system must preserve:

- what the user was thinking about
- why a decision was made
- how context evolved

Interruptions should be minimized.

---

# 6. Information Hierarchy Rule

Priority of information:

1. Decision-relevant context
2. Risk exposure
3. Scenario changes
4. Market noise

Never surface noise above decision context.

---

# 7. Uncertainty Representation Rule

Uncertainty must be visible, not hidden.

System should explicitly show:
- confidence levels
- scenario divergence
- regime instability

---

# 8. AI UX Role

AI assists cognition:

- summarizes complexity
- highlights relevant shifts
- clusters scenarios
- reduces cognitive load

AI does NOT:
- replace decision-making
- obscure reasoning paths
- produce opaque outputs

---

# 9. Anti-Dashboard Principle

TradeForge MUST avoid:

- static dashboards
- disconnected widgets
- fragmented views
- tab-heavy navigation systems

Everything must exist inside:
> continuous decision context

---

# Final Principle

TradeForge UX is not about presenting data.

It is about structuring thought under uncertainty.
