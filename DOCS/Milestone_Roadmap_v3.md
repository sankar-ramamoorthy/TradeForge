# Milestone Roadmap v3 — Cognitive Advisory Evolution

> Historical source note: this proposed roadmap was integrated into
> `DOCS/Milestone_Roadmap_v2.md` under TF-F044. Going forward, roadmap v2
> remains the active planning authority.

# Strategic Direction Shift

TradeForge is no longer primarily evolving toward:

- signal generation
- autonomous trading
- RL portfolio optimization
- predictive automation
- algorithmic execution

TradeForge is instead evolving toward:

```text
a replayable discretionary cognition operating system
````

focused on:

* machine-assisted discovery
* evidence accumulation
* contextual interpretation
* behavioral discipline
* attention allocation
* cognitive replayability
* structured discretionary reasoning

while preserving:

```text
Human Decision Sovereignty
```

as a non-negotiable invariant.

---

# Architectural Reframing

## The Machine Is Responsible For

* broad market attention
* candidate discovery
* contextual enrichment
* evidence accumulation
* anomaly detection
* historical comparison
* memory persistence
* advisory interpretation
* behavioral pattern surfacing

## The Human Is Responsible For

* judgment
* ambiguity handling
* discretionary interpretation
* risk acceptance
* plan approval
* execution decisions
* accountability

---

# New Core Principle

TradeForge does NOT attempt to answer:

```text
"What should I buy?"
```

TradeForge instead attempts to support:

```text
"What deserves my attention?
What evidence exists?
What risks am I ignoring?
How am I reasoning?
Is my process improving?"
```

# M12 — Advisory Observation And Cognitive Evidence Layer

**Status:** Planned

---

# Semantic Intent

Introduce machine-assisted evidence accumulation while preserving explicit separation between advisory observations and operator-owned lifecycle state.

---

# Architectural Significance

TradeForge currently supports:

* replayable workflows
* contextual market overlays
* structured cognitive artifacts
* provider-backed advisory context

However, the system does not yet possess a canonical model for:

```text
machine-originated observations
```

M12 introduces the first true:

```text
advisory cognition layer
```

without allowing AI or automated systems to mutate discretionary lifecycle authority.

---

# Core Principle

TradeForge must distinguish between:

## Advisory Space

```text
Observation
Signal
Context
Interpretation
Candidate
```

and:

## Commitment Space

```text
Trade Idea
Thesis
Plan
Approval
Execution
```

Machine-generated cognition remains advisory.

Human commitment remains authoritative.
